# 線上借用表（資源教室空間器材借用系統）

網址：https://educeduc-alt.github.io/resource-room/線上借用表/

學生申請、老師審核與點交、借用登記冊、借用名單、滿意度問卷，資料存在一份 Google 試算表。

## 檔案
- `index.html`：網頁本體
- `apps-script.gs`：貼到 Google 試算表 Apps Script 的資料庫程式（含管理密碼，**不要**分享給學生）

## 一次性設定（約 10 分鐘）
1. 用學校 Google 帳號建立一份新的 Google 試算表，命名「資源教室線上借用表」。
2. 選單「擴充功能 → Apps Script」，刪掉原本的內容，把 `apps-script.gs` 全部貼上，按儲存。
3. （建議）把 `ADMIN_PASSWORD` 改成新密碼。
4. 上方函式選單選「初始化」→ 按「執行」→ 依畫面授權（「進階 → 前往（不安全）」是 Google 對自建程式的固定提示）。試算表會出現「器材清單」等分頁。
5. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，複製「網頁應用程式網址」（https://script.google.com/macros/s/…/exec）。
7. 網址已填入 `index.html` 的 `API_URL`。重新部署時請用「管理部署作業 → 編輯 → 新版本」，網址才不會變。

`API_URL` 留空時，網頁是「展示版」，資料只存在自己的瀏覽器。

## 老師怎麼看資料
- 網頁「資源教室登入」→ 審核與點交、借用登記冊、借用名單、滿意度統計、設定。
- 直接開試算表：「申請紀錄」「借用登記冊」「滿意度問卷」「借用名單」「器材清單」分頁會自動更新（請勿手動修改「_資料」分頁）。

## 學生怎麼辨識身分
學生不需要帳號，以「學號 + 聯絡電話」辨識。換手機或電腦時，在「學生/職員申請」輸入同樣的學號與電話即可看到自己的申請。資源教室的共用電腦用完請按「切換身分」。

## 修改程式後
Apps Script 改過程式要「部署 → 管理部署作業 → 編輯 → 版本：新版本」才會生效，網址不變。
