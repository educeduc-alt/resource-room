# 資源教室宣導品倉庫管理

悅讀書房（資源教室）與 Q 棟地下室倉庫的宣導品庫存、領用登記、位置圖，以及圖書位置查詢。

## 檔案
- `index.html`：網頁本體（直接用瀏覽器打開也能用）
- `p00.jpg`…`p67.jpg`：宣導品照片（`t/` 為縮圖）
- `catalog.json`：圖書、影片清單
- `apps-script.gs`：雲端同步用的 Google Apps Script

## 兩層畫面
- **外層（預設）：工讀生登記**　點餐式畫面，選「領出／補進」與地點，用 ＋／－ 選數量，按「確認」檢查後送出。看不到紀錄、位置圖、圖書等內部資料。
- **內層：管理**　按右上「🔒 管理」輸入管理密碼進入。管理過的裝置會記住，按「🔒 工讀生畫面」可鎖回外層。

## 資料儲存
沒設定雲端時，修改內容只存在各自瀏覽器中。請定期在「庫存總覽」按「匯出備份」保存 JSON 檔。

## 雲端同步設定
工讀生用自己的手機登記，需要一個共用的地方存資料。這裡用你自己的 Google 帳號（免費），資料存在你的 Google 雲端硬碟，登記紀錄也會自動寫進一份 Google 試算表。

1. 到 Google 雲端硬碟新增一份 **Google 試算表**（例如命名「資源教室庫存紀錄」）。
2. 試算表上方選單「**擴充功能**」→「**Apps Script**」。
3. 把 [`apps-script.gs`](apps-script.gs) 的內容全部貼上，取代原本的程式碼（網站管理頁「☁ 雲端同步」裡有「複製程式碼」按鈕）。
4. 修改最上面兩行：
   - `STAFF_CODE`：工讀生代碼（給工讀生用）
   - `ADMIN_KEY`：管理密碼（只有你知道）
   然後按「儲存」💾。
5. 右上角「**部署**」→「**新增部署作業**」→ 齒輪選「**網頁應用程式**」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」，依指示授權（若出現「Google 尚未驗證這個應用程式」，按「進階」→「前往…（不安全）」，這是你自己寫的程式）。
6. 複製「網頁應用程式」網址（`https://script.google.com/macros/s/…/exec`）。
7. 打開網站 →「🔒 管理」進入 → 右上「☁ 雲端同步」→ 貼上網址與管理密碼 →「連線並同步」。第一次會把這台電腦的資料上傳到雲端。
8. 在同一個設定視窗填入工讀生代碼，會產生**工讀生連結與 QR code**，給工讀生掃一次就設定好了。

之後修改 `apps-script.gs`（例如換密碼）：「部署」→「管理部署作業」→ 鉛筆 → 版本選「新版本」→「部署」，網址不變。

試算表會自動出現兩個分頁：「領用紀錄」（每筆領出／補進）與「目前庫存」。
