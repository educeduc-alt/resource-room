# 資源教室活動資料台

活動辦完只填「中心活動辦理列表」，其他表單從這裡產出：

- 特推會業務報告文字、附件二、附件四
- table7_4 活動填報 .xls
- 生命教育指標（學年度場次／人次、佐證照片說明）
- 學期末：活動辦理列表 → 活動總表格式
- 自選欄位 CSV
- 活動分類：依資源教室活動統計表「活動分類指標」自動分 7 類（師生聯繫會議、心理成長團體、宣導活動、聯誼性質活動、學生知能課程、教師輔導知能研習、特推會）與適應生活／生涯轉銜；匯入統計表後沿用已分好的類別，可下載統計表 A～K 欄格式
- 業務分工：依 115.02.23 業務分工表，自動把活動歸到承辦人（ISP 依個管系所），可只看某位承辦人的活動、業務清單與學年度輪值

## 使用
開啟後是簡易畫面：把總表 Excel／Word 丟進去，下方列出可複製與可下載的表單。逐筆檢查請按右上「進階」。

可匯入：活動總表、中心活動辦理列表、資源教室活動統計表（.xlsx），ISP 個別化支持計畫（.docx）。

1. 從 Google 試算表下載「活動總表」「中心活動辦理列表」為 .xlsx（可再加資源教室活動統計表，用來沿用活動分類）
2. 拖進「① 匯入資料」
3. 選學期，到各頁下載或複製

資料只存在使用者瀏覽器中，不會上傳到 GitHub。
